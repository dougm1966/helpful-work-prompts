# Helpful Work Prompts

A personal library of prompts that helped produce useful work. Each saved prompt explains when to use it, the results it produced, and any context needed to reuse it.

## Save a prompt from any conversation

Tell an agent with write access to this repository:

> Save the prompt we just ran to https://github.com/dougm1966/helpful-work-prompts. Read AGENTS.md, recover the exact prompt from this conversation, and save it with a clear title, description, and summary of the results. Add it to the index and return the saved file link. Remove private details before publishing, and disclose any changes.

The agent needs access to both the original conversation and this repository. A GitHub connection alone does not guarantee write access. If the original prompt is unavailable, the agent should ask for it instead of guessing.

## How entries work

- Save one Markdown file per prompt under `prompts/`, using a descriptive lowercase filename.
- Start with [the entry template](templates/prompt.md).
- Keep the reusable prompt separate from descriptions and result notes.
- Distinguish results actually observed from results merely expected.
- Replace private names, paths, credentials, and client details with clear placeholders. Never publish private reports by default.

See [AGENTS.md](AGENTS.md) for the full save procedure. The library starts empty because the earlier prompt mentioned during setup was not available in this conversation.
